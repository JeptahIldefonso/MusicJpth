# Music Oasis

> A fast, offline-first local music player built for a smooth, private, native-feeling experience on Android and Desktop.

Music Oasis scans your device for music files, builds a local SQLite library, and plays music without any internet connection. Features include:

- **Fast performance** with efficient pagination and lazy loading
- **Local music scanning** and metadata extraction
- **Offline playback** with background audio and system media controls
- **SQLite-backed library** for quick queries and persistent state
- **Privacy-first** – no data leaves the device
- **Beautiful UI** with gradient themes and Spotify‑style navigation
- **Cross‑platform** – runs on Android phones and desktop (Windows/macOS/Linux)

## Installation
```bash
# Clone the repository
git clone https://github.com/JeptahIldefonso/MusicJpth.git
cd MusicJpth

# Install dependencies
flutter pub get

# Run on a device or emulator
flutter run
```

## Building
- **Debug APK** (for development): `flutter build apk --debug`
- **Release APK** (for distribution): `flutter build apk --release`
