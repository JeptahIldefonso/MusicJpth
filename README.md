# Music Oasis

> A fast, offline-first local music player built for a smooth, private, native-feeling experience.

Music Oasis scans music files stored on the user's device, builds a local music library, and plays music without requiring an internet connection.

The application is designed around:

- ⚡ Fast performance
- 📁 Local music scanning
- 🎵 Offline playback
- 🗄️ SQLite library
- 🔒 Privacy-first local storage
- 🎧 Background playback
- 🔔 System media controls
- 📱 Mobile-first navigation
- 🖥️ Desktop support
